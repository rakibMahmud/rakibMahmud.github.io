* **Developed** a complete compiler for a custom programming language, built from the front end down.
* **Implemented** lexical analysis with Flex, producing the token stream from raw source.
* **Designed** an unambiguous grammar and implemented syntax analysis with Bison for the language's constructs.
* **Built** the code optimization and generation stages, transforming parse output into optimized target code.
* **Engineered** robust error handling with recovery, so a single syntax error does not cascade into a wall of spurious diagnostics — the difference between a compiler that teaches and one that frustrates.
