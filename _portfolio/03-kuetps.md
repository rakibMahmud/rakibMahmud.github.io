* **Created** a full-stack web platform for the KUET Photographic Society, the club I later served as President.
* **Implemented** user authentication with session management and access control.
* **Developed** the image interaction system — upload, like, dislike and comment — as the core social loop of the platform.
* **Designed** a normalized MS SQL Server schema and implemented secure database storage for user data and uploaded media.
* **Built** profile customization so members can present their own portfolio within the society's site.
